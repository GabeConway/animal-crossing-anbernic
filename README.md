# OpenCrossing


OpenCrossing is a port of Animal Crossing: Population Growing based on the OpenCrossing project.


This is my fork of the project, with work focused mainly on getting OpenCrossing running on LG webos TVs


My main goal with this fork was getting it running on my lg tv through webos.


# webOS


The webOS port currently targets the 32-bit arm application environment used by LG webOS.


The webOS build uses the ARMv7 webOS toolchain.


I've also documented the webOS build process here:


docs/README.webOS.md


# Game data


The original game data is not provided in here.


You need to provide your own *legally* obtained copy of the game.


# Building


The normal OpenCrossing build process is described by the project itself.


For the webOS-specific build instructions, see:


docs/README.webOS.md


# Status


THE WEBOS PORT IS STILL A WORK-IN-PROGRESS.
